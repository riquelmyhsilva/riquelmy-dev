Este projeto implementa um pipeline completo de previsão para planejamento de demanda. Ele ingere dados históricos de vendas, gera features temporais e de defasagem (lags), treina modelos baseados em gradiente boosted por categoria de produto e expõe predições através de uma API REST.

Entre as principais decisões técnicas estão o uso de previsão recursiva multi-etapas, validação walk-forward para estimativas realistas de desempenho e conteinerização completa da aplicação com Docker Compose para deploys reproduzíveis.
